Global Sync

PUBLISH TO VISITORS

Settings, tools and bots are stored in this browser and also published through your Cloudflare Worker (needs the bridge URL below, a KV namespace bound as MWAY_KV and the ADMIN_TOKEN secret). Visitors on any device load the published copy. API keys and the bridge URL are never published to visitors. API keys you type below are sent only to your Worker (stored in its KV) and take effect immediately. "Refresh Server / Force Update" re-publishes everything and makes every open page re-apply it within ~10-15 s.

Steam API Provisioning Tool

PROFILE SYNC

With a bridge URL set, every Steam, Leetify, CSFloat and price request goes through your own Cloudflare Worker, and Steam logins are confirmed by the Worker itself. If the Worker holds STEAM_API_KEY, the key field above can stay empty and the key never reaches the browser. The key is stored in plain text in this browser's localStorage. Browsers block direct calls to the Steam API (CORS), so syncing automatically goes through public CORS proxies (corsproxy.io, with fallbacks). Those proxies can see your key; for a private setup enter your own proxy above. The CSFloat, Leetify and HLTV keys are stored the same way. HLTV has no public API, so the rating only appears if you point the endpoint at a service you run or trust (it may return a plain number or JSON with a "rating" field).
